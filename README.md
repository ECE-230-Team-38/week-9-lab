### In plain English describe the function and use of a multiplexer.
A multiplexer just takes multiple input signals and chooses one to send to the output all based on selector bits. It just acts like a switchboard and decides which data source gets through. Multiplexers are used when several signals share a single communication line. 

### In plain English describe the function and use of a demultiplexer.
A demultiplexer does the exact opposite of a multiplexer it just sends one input signal to one of many outputs. It uses selector bits to decide which output recieves the data. DEMUX circuits are usually used in systems that distribute information to different destinations.

### What other uses might these circuits have? (Think Shannon’s)
Multiplexers and demutiplexers can just model information flow and switching in communication theory. According to Shannons idea they just help efficiently manage bandwidth and minimize the signal loss but they also are used in CPUs and memory addressing. They basically just optimize how data is transmitted and recieved.
